# ☕ CoffeeMind AI

CoffeeMind AI, kullanıcının ruh haline, hava durumuna ve kahve tercihlerine (süt, tatlılık, sertlik) göre en ideal kahveyi öneren akıllı bir web uygulamasıdır.

## 🚀 Özellikler
- **Dinamik Veri Yönetimi:** Kahve önerileri ve detayları `coffee_data.csv` dosyasından dinamik olarak okunur.
- **SQLite Entegrasyonu:** Kullanıcıların verdiği beğeniler ve puanlar yerel bir SQLite veritabanında saklanır.
- **Modern Arayüz:** Streamlit kütüphanesi ile minimalist ve kullanıcı dostu arayüz tasarımı.

## 🛠️ Kullanılan Teknolojiler
- Python 3
- Streamlit (Web UI)
- Pandas (Veri Yönetimi)
- SQLite3 (Veritabanı)
